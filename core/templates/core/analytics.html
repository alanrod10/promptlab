¿Cómo se integra PromptLab con la Ciencia de Datos?
1. Recolección de Datos Estructurados Cada vez que se usa la aplicación, se guarda un registro en la base de datos SQLite con el texto original, la categoría, la técnica elegida y el texto mejorado.
2. Medición Cuantitativa (Rúbrica 0-100) El sistema evalúa 5 criterios objetivos (Rol, Objetivo, Contexto, Instrucciones y Formato) para medir con números cuántos puntos de calidad ganó el prompt y cuántas palabras se agregaron.
3. Exportación CSV para Machine Learning El botón Descargar Dataset (.CSV) genera una tabla limpia lista para abrir en Python, Pandas o Google Colab y entrenar modelos que clasifiquen textos o predigan qué prompts prefiere el usuario (usando la columna es_favorito).
