Ciclo de Vida del Dato y Aplicación en Ciencia de Datos
1. Captura y Almacenamiento (ETL) Cada interacción persiste en SQLite capturando texto no estructurado (original_text), metadatos de dominio, nivel de transformación y marca temporal.
2. Feature Engineering y Feedback Se calculan métricas derivadas (conteo léxico y ratio de expansión) y se registra la variable binaria is_favorite como señal de calidad humana (Ground Truth).
3. Dataset Listo para Machine Learning El archivo promptlab_dataset.csv permite entrenar clasificadores supervisados de intención (TF-IDF + Regresión Logística / Naive Bayes) en Python y Pandas.
